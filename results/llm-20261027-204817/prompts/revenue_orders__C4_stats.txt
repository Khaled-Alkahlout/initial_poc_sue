## Originele query
```sql
-- name: revenue_orders
-- owner: finance
-- params: tenant_id, from, to
-- Revenue-bearing orders in a window. Period grouping (day/week/month, week
-- start, fiscal month boundaries) is applied by the service layer so the same
-- query feeds every grouping the dashboard offers.
SELECT o.id,
       o.created_at,
       o.status,
       o.total_cents,
       o.currency
  FROM orders o
 WHERE o.tenant_id = %(tenant_id)s
   AND o.created_at >= %(from)s
   AND o.created_at <  %(to)s
   AND o.status IN ('paid', 'processing', 'shipped', 'delivered')
```

## Schema van de gebruikte tabellen (kolommen, constraints, indexen)
```
TABLE orders (
  id uuid NOT NULL,
  tenant_id uuid NOT NULL,
  customer_id uuid NOT NULL,
  status text NOT NULL,
  currency text NOT NULL,
  subtotal_cents bigint NOT NULL,
  discount_cents bigint NOT NULL,
  shipping_cents bigint NOT NULL,
  total_cents bigint NOT NULL,
  shipping_address_id uuid,
  billing_address_id uuid,
  notes text,
  channel text NOT NULL,
  created_at timestamp without time zone NOT NULL,
  updated_at timestamp with time zone NOT NULL,
  promotion_id uuid,
  reference text
)
  CONSTRAINT FOREIGN KEY (billing_address_id) REFERENCES customer_addresses(id) ON DELETE SET NULL
  CONSTRAINT FOREIGN KEY (customer_id) REFERENCES customers(id) ON DELETE CASCADE
  CONSTRAINT FOREIGN KEY (promotion_id) REFERENCES promotions(id) ON DELETE SET NULL
  CONSTRAINT FOREIGN KEY (shipping_address_id) REFERENCES customer_addresses(id) ON DELETE SET NULL
  CONSTRAINT FOREIGN KEY (tenant_id) REFERENCES tenants(id)
  CONSTRAINT PRIMARY KEY (id)
  CREATE INDEX orders_created_at_tenant_idx ON public.orders USING btree (created_at, tenant_id)
  CREATE UNIQUE INDEX orders_pkey ON public.orders USING btree (id)
  CREATE INDEX orders_total_eur_idx ON public.orders USING btree (tenant_id, ((total_cents / 100)) DESC)
```
